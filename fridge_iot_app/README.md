# 冷蔵庫 IoT 状態モニター（研究用プロトタイプ）

## 概要
庫内温度・室温・湿度・電流/電力・扉状態を保存し、ブラウザで表示するWebアプリの土台です。
現時点では実センサーの自動読取ではなく、画面を試せるデモデータ機能と、外部端末からデータを送るAPIを実装しています。

> 注意：表示する「正常・注意・警告」は研究用の仮ルールです。食品の腐敗や安全性を判定・保証するものではありません。実際の冷蔵庫の電源配線や電流センサーの接続は感電・火災の危険があるため、このサンプルを見ながら自己判断で作業せず、必ず指導教員・有資格者の管理下で安全な計測方法を確認してください。

## 起動方法（Windows / Ubuntu）
Python 3.10以降を用意し、このフォルダで実行します。

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Ubuntu:
source .venv/bin/activate

python -m pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

ブラウザで http://127.0.0.1:8000 を開き、「デモ計測を追加」を押すと値とグラフが更新されます。
同じネットワーク上の別端末からのアクセスが必要な場合は、ネットワーク構成・ファイアウォール・認証を指導者と確認してから公開範囲を設定してください。

## データ送信API
`POST /api/reading` にJSONを送るとデータベースに保存されます。

```json
{
  "device_id": "fridge-01",
  "inside_temp": 4.2,
  "room_temp": 25.1,
  "humidity": 48.0,
  "current_a": 0.32,
  "power_w": 31.5,
  "door_open": false
}
```

`recorded_at` は省略可能（省略時はサーバー時刻を使用）。単位は温度=℃、湿度=%、電流=A、電力=Wです。
- `GET /api/status` 最新値と試作判定
- `GET /api/history?limit=120` 履歴（最大1000件）
- `DELETE /api/history` 履歴削除
- `POST /api/demo` デモ用の計測値を1件追加

## 研究を進める際の拡張点
1. 実際に採用するマイコンとセンサーの仕様に合わせて読取処理を実装する。
2. センサーの校正、設置位置、サンプリング間隔、通信断時の再送を検討する。
3. 扉スイッチなどを安全に追加できるか検討する。扉開放時間を直接測れない間は、温度・電力からの推定と区別して扱う。
4. 動的アラートの条件を実験データから調整し、固定しきい値方式と比較する。
5. 学外公開する場合は認証、HTTPS、入力制限、バックアップ等を追加する。
